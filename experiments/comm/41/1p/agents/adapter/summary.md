I wrote `design.yaml`, `frame.md` and `requirements.yaml` for the stateless function `candidate(n)`, and `fcp lint` reports clean. Each cycle after the reset is one call. The input is `n`, 10 bits (0 to 1,023). The outputs are `result`, a 21-bit integer (0 to 2,097,151), and a 2-bit `outcome`: 0 means it returned an integer that fits, 1 means it raised any exception or didn't finish, and 2 means it returned anything else. `raises` is `[]` because the request names no exception. The request doesn't bound `n`, so 0 to 1,023 is my choice. The output is wide enough for every value up to 2n² at that range, and the scope tests all 1,024 values of `n`. Two things in the request itself matter: it stops mid-sentence ("Two cars are said to collide"), and the signature has no return type. So I named the output a neutral `result`, and `frame.md` says the returned value is read as one integer, with `None` or another type counting as outcome 2. `frame.md` also says negative arguments and values above 1,023 are not part of the trace. It has one frame rule, F-ZERO (`outcome != 0 -> result == 0`), which cites R-FR-1, a verbatim quote of `frame.md` line 40 placed with `fcp anchor`. I deleted the temporary `draft.yaml` I used for anchoring.
