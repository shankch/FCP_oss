I wrote `design.yaml`, `frame.md` and `requirements.yaml` for `is_equal_to_sum_even(n)`, and `fcp lint` reports no errors. Each cycle is one call, with no memory between calls. The argument `n` goes on a 16-bit input signal, so it covers 0 to 65,535; `frame.md` says that negative numbers and anything above 65,535 are not part of the trace. That width is my own choice, because the request gives no range for `n`. The returned value goes on a 1-bit output, `result`. Since the request names no exception, `raises` is `[]` and the 2-bit `outcome` uses three codes: 0 it returned True or False, 1 it raised any exception or never finished, 2 it returned anything else. There is one frame rule, F-ZERO (`outcome != 0 -> !result`). It cites R-FR-1, a definition quoted word for word from `frame.md`, and `fcp anchor` filled in its line number (36) from `draft.yaml`, which I left in the workspace. The scope tests `n` on every value from 0 to 1000 plus 400 random ones, and adds 4 by name because it is the only number the request mentions. Be aware that `spec.md` is cut off mid-sentence ("the sum of exactly 4 "), so whoever formalizes it gets an incomplete request; the design only describes the interface and doesn't try to fill in the missing part.
