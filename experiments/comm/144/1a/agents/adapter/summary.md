I wrote `design.yaml`, `frame.md` and the frame requirement for `simplify(a, b)`, and `fcp lint` reports the bundle clean. Each cycle after the reset in cycle 0 is one independent call. The two arguments are input strings `a` and `b`, each up to 16 characters with codes 0–255; the 16-character limit is my choice, since the request puts no bound on the numbers. The returned boolean is the 1-bit output `result` (1 means True). Because the request names no exception, `raises` is `[]`, so the 2-bit `outcome` is 0 if the function returned True or False, 1 if it raised any exception or didn't finish, and 2 if it returned anything else. The `function` section gives the name, the two `str` arguments, the bool return, the outcome and a `scope`. That scope uses the alphabet `0123456789/`, 2000 random strings per argument, and the request's example fractions (`1/5`, `1/6`, `7/10` for `a`; `5/1`, `2/1`, `10/2` for `b`). `frame.md` explains the calls, how strings are carried, and the input and output tables. It says that longer strings, characters above code 255, non-string arguments and negative integers are not part of the trace.
