The function keeps no state between calls, and cycle 0 is reset. Each of the two string arguments is an input signal: 8 bits per character (codes 0 to 255) and at most 16 characters. The request doesn't bound string length and its longest example is 7 characters, so 16 is my own choice, picked to cover the examples with room to spare. The returned boolean is a 1-bit `result`. `outcome` is 2 bits, coded 0 for returned True or False, 1 for any exception or no answer, and 2 for anything else. The request names no exception, so `raises` is `[]`. F-CODE (`outcome <= 2`, citing R-FR-2) is my addition and not something you asked for: the adapter never produces code 3, and the rule stops the analyses from treating it as possible.
