The `brackets` argument is an input string signal of 8-bit characters (codes 0–255) with a `length` of 32. That covers the request's examples (up to 6 characters) plus longer strings, other characters and the empty string. The request sets no maximum length, so 32 is my choice, the same as in `code_mask`. The returned boolean goes on a 1-bit `result` signal. Because the request names no exception, `raises: []` and `outcome` is 2 bits: 0 means it returned True or False, 1 any exception or no answer, and 2 anything else.
